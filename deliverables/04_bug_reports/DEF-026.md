# DEF-026: Diner Can Destructively Cancel Another Diner's Paid Ticket via /trays/{id} (BOLA / IDOR)

- **Severity:** Blocker
- **Module / Route:** `/sut/mejamarmar/trays/{id}` & Ticket Cancel Endpoint
- **Spec Reference:** `MEJ-SEC-01` (Diner Object Ownership & Role Isolation), `MEJ-TKT-04`
- **Verified By:** Live browser verification (`ebcc33d0`, steps 90-98)

## Steps to Reproduce
1. Sign in as Diner `Nur Aisyah Rahman`.
2. Navigate directly to `https://www.worldbesttester.com/sut/mejamarmar/trays/1034` (belongs to Diner `Tan Wei Ling`).
3. Observe the active `"Cancel this ticket"` button on ticket `997` at `Roti Canai Tawa Emas` (`RM9.54`).
4. Click `"Cancel this ticket"` and confirm in the modal (`"Cancel ticket 997 at Roti Canai Tawa Emas?"`).

## Expected Result
Diner `Nur Aisyah Rahman` must receive `HTTP 403` / access denied when attempting to view or cancel a ticket owned by another diner (`Tan Wei Ling`).

## Actual Result
The server returns `HTTP 200`, executes the cancellation, displays `"Cancelled, refunded RM9.54"`, and updates `Tan Wei Ling`'s tray `T-1034` ticket `997` to `"Complete. Refunded: Roti Canai Tawa Emas RM9.54."`
