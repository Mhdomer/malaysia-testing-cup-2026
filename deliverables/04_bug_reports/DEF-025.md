# DEF-025: Tapau Container Fee Charges RM0.30 Per Line Instead of Per Dish Unit (`MEJ-TOT-02`)

## WBT Form Fields

- **Summary \*:** Tapau container fee charges RM0.30 per Tapau line instead of RM0.30 per dish unit on the line (MEJ-TOT-02)
- **Area of Impact \*:** Tray Totals & Tapau Container Billing (MEJ-TOT-02)
- **Issue Type \*:** Functional
- **Severity \*:** Major
- **Priority \*:** High
- **Frequency \*:** Always
- **Product Risk \*:** High
- **Device Type:** Desktop
- **OS Version:** CachyOS Linux
- **Browser Type:** Chrome

---

### Description \*
Per `MEJ-TOT-02`, `"Containers is RM0.30 for every dish on a Tapau line; Dine-in lines use none."` When a diner orders multiple units (`qty > 1`) of a dish on a Tapau line, each packed dish requires a container (`quantity * RM0.30`).

However, the SUT calculates `Containers` at a flat `RM0.30` per **Tapau line** regardless of the quantity on that line, undercharging container fees and downstream 6% Service tax whenever `quantity >= 2`:
- For `3 x Nasi lemak biasa` (`RM4.50` each) on one Tapau line, `Containers` shows **`RM0.30`** instead of `3 * RM0.30 = RM0.90`.
- For `3 x Nasi lemak biasa` (Tapau) + `2 x Nasi lemak ayam goreng` (Tapau) (`5` packed dishes across 2 Tapau lines), `Containers` shows **`RM0.60`** (`2 * RM0.30`) instead of `5 * RM0.30 = RM1.50`.

---

### Steps to Reproduce \*
1. Sign in as a diner (e.g., `hafiz.zulkifli@example.com` / `marmar2026`).
2. Add `3` units of `Nasi lemak biasa` (`RM4.50` each) and set the line to `Tapau`.
3. Open `/sut/mejamarmar/tray` and inspect the `Items`, `Containers`, `Service tax`, and `Tray total` breakdown.
4. Add a second `Tapau` dish line with quantity `2` (`2 x Nasi lemak ayam goreng`, `RM7.00` each) and re-inspect `Containers`.

---

### Expected Result \*
Per `MEJ-TOT-02` ("RM0.30 for every dish on a Tapau line"):
- `3 x Nasi lemak biasa` (`Tapau`): `Containers` = `3 * RM0.30` = **`RM0.90`**.
- `3 x Nasi lemak biasa` + `2 x Nasi lemak ayam goreng` (`5` Tapau dishes): `Containers` = `5 * RM0.30` = **`RM1.50`**.

---

### Actual Result \*
- On `3 x Nasi lemak biasa` (`Tapau`), `Containers` is **`RM0.30`** (`Items: RM13.50`, `Containers: RM0.30`, `Service tax: RM0.83`, `Tray total: RM14.63`).
- On `3 x Nasi lemak biasa` + `2 x Nasi lemak ayam goreng` (`Tapau`), `Containers` is **`RM0.60`** (`Items: RM27.50`, `Containers: RM0.60`, `Service tax: RM1.69`, `Tray total: RM29.79`).

---

### Additional Information
- **Specification Reference:** `MEJ-FRS-001 v1.0`, Section 7 (`MEJ-TOT-02`: "Containers is RM0.30 for every dish on a Tapau line; Dine-in lines use none.").
- **Root Cause:** Backend multiplies `RM0.30` by `tapau_lines.length` instead of summing `line.quantity * 0.30` across Tapau lines, likely because the specification's Section 2 worked example only showed `1 x Coklat ais, Tapau`.
