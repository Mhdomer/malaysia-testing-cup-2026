# DEF-004: Off-by-One Limit Blocks Adding Dishes from a 5th Stall to a Tray

- **Summary \*:** Off-by-One Limit Blocks Adding Dishes from a 5th Stall to a Tray (MEJ-TRY-02)
- **Device Type:** Desktop | **OS Version:** CachyOS Linux | **Browser Type:** Chrome
- **Priority \*:** High
- **Severity \*:** Major
- **Area of Impact \*:** Tray Management / Multi-Stall Order Validation
- **Frequency \*:** Always
- **Product Risk \*:** Medium
- **Issue Type \*:** Functional

---

## Description \*
An off-by-one boundary error (`< 5` or `>= 4` check instead of `> 5`) prevents diners from adding dishes from a 5th distinct stall to an active tray. Although the specification and error message both state that a tray can hold dishes from up to 5 stalls, the application blocks the user as soon as 4 stalls are present on the tray.

## Steps to Reproduce \*
1. Log in as a diner and start a new tray.
2. Add at least 1 dish from Stall 1.
3. Add at least 1 dish from Stall 2.
4. Add at least 1 dish from Stall 3.
5. Add at least 1 dish from Stall 4 (tray now contains dishes from 4 distinct stalls).
6. Attempt to add a dish from Stall 5 to the same tray.

## Expected Result \*
Per `MEJ-TRY-02`, a tray holds dishes from **at most 5 stalls** (`<= 5`). Adding a dish from a 5th distinct stall should succeed, and only attempting to add from a 6th distinct stall should be blocked.

## Actual Result \*
With dishes from only 4 stalls on the tray, attempting to add a dish from a 5th stall is blocked with the error message:
`"A tray can hold dishes from up to 5 stalls. Send this tray first, then start another."`

## Additional Information
- **Spec Reference:** `MEJ-TRY-02`
- **Root Cause (Likely):** Off-by-one comparison (`distinctStalls.length >= 4` or `>= MAX_STALLS - 1`) before inserting the new stall's dish.
