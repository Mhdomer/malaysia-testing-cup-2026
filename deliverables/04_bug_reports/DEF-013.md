# DEF-013: Open Redirect on Diner Sign-In via `next` Query Parameter (`MEJ-ACC-01`, `MEJ-SEC-06`)

## WBT Form Fields

- **Summary \*:** Open redirect on diner sign-in via next query parameter allows external phishing redirects (MEJ-ACC-01, MEJ-SEC-06)
- **Area of Impact \*:** Diner Authentication / Sign-In Redirect (MEJ-SEC-06)
- **Issue Type \*:** Security
- **Severity \*:** Critical
- **Priority \*:** High
- **Frequency \*:** Always
- **Product Risk \*:** High
- **Device Type:** Desktop
- **OS Version:** CachyOS Linux
- **Browser Type:** Chrome

---

### Description \*
The diner sign-in flow (`/sut/mejamarmar/sign-in`) accepts an unvalidated `next` query parameter and redirects the browser to arbitrary external URLs after successful authentication.

Per `MEJ-ACC-01` and `MEJ-SEC-06`, sign-in must return only to pages of Meja Marmar itself. Navigating to `/sut/mejamarmar/sign-in?next=https://evil.com` and signing in with valid credentials redirects the browser externally to `https://evil.com/`, enabling credential phishing chains where victims trust the legitimate `worldbesttester.com` login URL before being handed off to an attacker-controlled domain.

---

### Steps to Reproduce \*
1. Open the browser and navigate to `https://www.worldbesttester.com/sut/mejamarmar/sign-in?next=https://evil.com`.
2. Enter valid diner credentials (e.g., `nuraisyah.rahman@example.com`).
3. Submit the sign-in form.
4. Observe the post-login redirect destination in the browser address bar and network response.

---

### Expected Result \*
Per `MEJ-ACC-01` and `MEJ-SEC-06`, the server must validate the `next` parameter against an allowlist of same-origin Meja Marmar paths and ignore or reject external URLs, redirecting the user to a safe default Meja Marmar page instead.

---

### Actual Result \*
After valid authentication, the server redirects the browser externally to `https://evil.com/`.

---

### Additional Information
- **Specification References:** `MEJ-ACC-01`, `MEJ-SEC-06` (Sign-in redirect restricted to Meja Marmar pages).
- **CWE / OWASP:** CWE-601 (URL Redirection to Untrusted Site / Open Redirect).
- **Affected URL:** `https://www.worldbesttester.com/sut/mejamarmar/sign-in?next=https://evil.com`
