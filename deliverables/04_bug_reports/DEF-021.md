# DEF-021: Kitchen Display Single-Key Shortcuts (S, C, H) Fire While Typing Inside "Message on the board" Text Input (MEJ-SEC-05)

## WBT Form Fields

- **Summary \*:** Kitchen Display single-key shortcuts (S, C, H) fire while typing inside "Message on the board" text input (MEJ-SEC-05)
- **Area of Impact \*:** Dapur / Kitchen Display Keyboard Shortcuts & Accessibility (MEJ-SEC-05)
- **Issue Type \*:** Functional
- **Severity \*:** Major
- **Priority \*:** High
- **Frequency \*:** Always
- **Product Risk \*:** Medium
- **Device Type:** Desktop
- **OS Version:** CachyOS Linux
- **Browser Type:** Chrome

---

### Description \*
Per `MEJ-SEC-05` and WCAG 2.1 SC 2.1.4 (Character Key Shortcuts), single-key shortcuts `S`, `C`, and `H` on the Kitchen Display must act "only while the focus is in no text field or list".

Instead, the global `keydown` handler on `/sut/mejamarmar/dapur/kitchen/1` (and `/kitchen/2`) does not ignore events originating from `<input>` or `<textarea>` elements. When staff focus inside the `"Message on the board"` text input and type normal words containing `s`, `c`, or `h`, the keyboard shortcuts fire simultaneously, erratically advancing active kitchen tickets while typing a board message.

---

### Steps to Reproduce \*
1. Sign in to Dapur and navigate to `/sut/mejamarmar/dapur/kitchen/1` (or `/sut/mejamarmar/dapur/kitchen/2`) with active tickets in the queue.
2. Click inside the `"Message on the board"` text input field to give it keyboard focus.
3. Type `"Special lunch hot soup"` into the input field.
4. Observe the kitchen ticket statuses and board state as the letters `s`, `c`, and `h` are typed.

---

### Expected Result \*
Per `MEJ-SEC-05` and WCAG 2.1 SC 2.1.4, single-key shortcuts (`S`, `C`, `H`) are suppressed whenever focus is inside a text field or list. Typing `"Special lunch hot soup"` inside `"Message on the board"` should only populate the text input without triggering any ticket state transitions.

---

### Actual Result \*
Typing `"Special lunch hot soup"` inside `"Message on the board"` triggers the global `keydown` shortcuts for `s`, `c`, and `h`, erratically advancing kitchen tickets in the background while the user is typing.

---
