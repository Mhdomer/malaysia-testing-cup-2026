# DEF-022: Kitchen Display Omits Primary <h1> Heading, Breaking Accessibility Heading Hierarchy (WCAG 2.1 SC 1.3.1 / 2.4.6)

## WBT Form Fields

- **Summary \*:** Kitchen Display omits primary <h1> heading, breaking accessibility heading hierarchy (WCAG 2.1 SC 1.3.1 / 2.4.6)
- **Area of Impact \*:** Dapur / Kitchen Display Accessibility (WCAG 2.1 AA)
- **Issue Type \*:** UI
- **Severity \*:** Minor
- **Priority \*:** Low
- **Frequency \*:** Always
- **Product Risk \*:** Low
- **Device Type:** Desktop
- **OS Version:** CachyOS Linux
- **Browser Type:** Chrome

---

### Description \*
On the Dapur Kitchen Display pages (`/sut/mejamarmar/dapur/kitchen/1`, `/kitchen/2`, and `/kitchen/5`), the DOM omits a primary `<h1>` heading (`h1Count: 0`) and begins the document outline directly with `<h2>` headings (`"Shortcuts: on"`, `"New"`, `"Cooking"`, `"Ready"`).

Missing a top-level `<h1>` landmark heading breaks logical document structure and impairs screen reader navigation, violating WCAG 2.1 SC 1.3.1 (Info and Relationships) and SC 2.4.6 (Headings and Labels).

---

### Steps to Reproduce \*
1. Sign in to Dapur and navigate to `/sut/mejamarmar/dapur/kitchen/1` (repeat on `/kitchen/2` and `/kitchen/5`).
2. Open Chrome DevTools Elements panel or run an accessibility / DOM outline check (`document.querySelectorAll('h1').length` and `document.querySelectorAll('h2')`).
3. Inspect the heading hierarchy of the rendered page.

---

### Expected Result \*
Each Kitchen Display page should contain a single descriptive primary `<h1>` heading (for example, the stall/kitchen name) before the secondary `<h2>` section headings (`"Shortcuts: on"`, `"New"`, `"Cooking"`, `"Ready"`), maintaining a valid WCAG 2.1 heading hierarchy.

---

### Actual Result \*
`document.querySelectorAll('h1').length` is `0` across `/kitchen/1`, `/kitchen/2`, and `/kitchen/5`. The heading tree starts directly at `<h2>` (`"Shortcuts: on"`, `"New"`, `"Cooking"`, `"Ready"`).

---

### Additional Information
- **Accessibility Reference:** WCAG 2.1 SC 1.3.1 (Info and Relationships) / SC 2.4.6 (Headings and Labels).
