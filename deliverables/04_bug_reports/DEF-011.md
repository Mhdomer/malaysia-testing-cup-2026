# DEF-011: IDOR Write + Full-Tray Over-Refund on Single Ticket Cancellation (`MEJ-SEC-01`, `MEJ-REF-03`) [GOLDEN BUG]

## WBT Form Fields

- **Summary \*:** IDOR Write + Full-Tray Over-Refund on Single Ticket Cancellation (MEJ-SEC-01, MEJ-REF-03)
- **Area of Impact \*:** Diner Trays & Refunds / Authorization (MEJ-SEC-01, MEJ-REF-03)
- **Issue Type \*:** Security
- **Severity \*:** Blocker
- **Priority \*:** Critical
- **Frequency \*:** Always
- **Product Risk \*:** High
- **Device Type:** Desktop
- **OS Version:** CachyOS Linux
- **Browser Type:** Chrome

---

### Description \*
Two critical flaws combine on the ticket cancellation endpoint `POST /sut/mejamarmar/trays/{tray_id}/tickets/{ticket_id}/cancel`:

1. **IDOR Write (`MEJ-SEC-01`):** The endpoint performs no server-side ownership verification on `tray_id`. Any authenticated diner can submit a cancellation request against another diner's tray and ticket, mutating order state and triggering balance refunds on a victim's account.
2. **Full-Tray Over-Refund (`MEJ-REF-03`):** When cancelling a single ticket on a multi-ticket tray, the server refunds the entire tray total instead of only the cancelled ticket's section total.

When authenticated as `nuraisyah.rahman@example.com`, submitting `POST /sut/mejamarmar/trays/1040/tickets/131/cancel` against another diner's tray `T-1040` succeeded without ownership validation, and cancelling single ticket `131` (section total `RM11.66`) triggered a refund of the entire tray total (`RM31.59`) instead of `RM11.66`.

---

### Steps to Reproduce \*
1. Sign in to Meja Marmar (`/sut/mejamarmar/sign-in`) as diner `nuraisyah.rahman@example.com`.
2. Identify another diner's multi-ticket tray (e.g., Tray `T-1040`, total `RM31.59`) containing ticket `131` (section total `RM11.66`).
3. Submit an authenticated `POST` request to `/sut/mejamarmar/trays/1040/tickets/131/cancel` using `nuraisyah.rahman@example.com`'s session.
4. Observe the server response, the state of ticket `131` on `T-1040`, and the refunded amount recorded against the tray/balance.

---

### Expected Result \*
1. Per `MEJ-SEC-01`, the server must verify that the authenticated diner owns tray `T-1040` and reject the cross-user cancellation request with `"Tray not found"` (403/404) without mutating the tray or issuing any refund.
2. Per `MEJ-REF-03`, cancelling a single ticket on a valid owned tray must refund only that ticket's section total (`RM11.66`), not the full tray total (`RM31.59`).

---

### Actual Result \*
The server accepted `POST /sut/mejamarmar/trays/1040/tickets/131/cancel` from `nuraisyah.rahman@example.com` on another diner's tray `T-1040`, cancelled ticket `131`, and refunded the full tray total (`RM31.59`) instead of ticket `131`'s section total (`RM11.66`).

---
